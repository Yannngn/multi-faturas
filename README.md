# multi-faturas
O multi-faturas é um script em Python projetado para automatizar sua gestão financeira. Ele consome faturas em PDF de múltiplas instituições bancárias, extrai dados e converte tudo para o formato CSV. Além disso, a ferramenta consolida todas as despesas em um único histórico de transações unificado, facilitando a análise minuciosa de gastos.
